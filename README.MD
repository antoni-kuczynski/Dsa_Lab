# Algorithms and Data Structures

This repository contains solutions and implementations for a series of algorithmic exercises.  
Each exercise is organized into its own dedicated branch (`cw1`, `cw2`, ..., `cw7`) to keep the topics cleanly separated.

## Branch Overview

### 🔹 [cw1 – Computational Complexity & Sorting Algorithms](../../tree/cw1)
Covers::sob: 
- Time and space complexity analysis  
- Classic sorting algorithms (e.g., Merge Sort, Quick Sort, Heap Sort)  
- Comparisons of algorithmic efficiency  

---

### 🔹 [cw2 – Hash Tables (Chaining Method)](../../tree/cw2)
Covers:
- Hash table construction  
- Collision handling using separate chaining  
- Analysis of expected performance  

---

### 🔹 [cw3 – Hash Tables (Open Addressing)](../../tree/cw3)
Covers:
- Open addressing strategies (linear probing, quadratic probing, double hashing)  
- Load factor considerations  
- Performance trade-offs  

---

### 🔹 [cw4 – Trees → Dictionaries](../../tree/cw4)
Covers:
- Tree-based dictionary implementations  
- Binary Search Trees, AVL Trees, or Red–Black Trees  
- Operations: insertion, deletion, search  

---

### 🔹 [cw5 – Greedy Algorithms (+ Compression Problems)](../../tree/cw5)
Covers:
- Greedy strategy design and correctness  
- Classic greedy problems  
- Compression-related tasks (e.g., Huffman coding)  

---

### 🔹 [cw6 – Dynamic Programming](../../tree/cw6)
Covers:
- Bottom-up and top-down DP approaches  
- Optimal substructure and overlapping subproblems  
- Classic DP tasks (knapsack, LIS, matrix chain multiplication, etc.)  

---

### 🔹 [cw7 – Graph Algorithms](../../tree/cw7)
Covers:
- Graph representations  
- BFS, DFS  
- Shortest paths (Dijkstra, Bellman–Ford)  
- MST algorithms (Kruskal, Prim)  

---

## Structure

Each branch contains:
- Source code  
- Example inputs/outputs  
- Notes or explanations for the implemented algorithms  

Feel free to explore each branch to dive into the specific topic.
